# YouthGuardian 青少年守护

Chrome 扩展程序，用于在 YouTube/Bilibili 建立频道白名单，仅展示允许频道的视频内容。

## 功能特性

- **频道白名单**：将信任的频道添加到白名单，非白名单视频自动隐藏
- **双平台支持**：同时支持 YouTube 和 Bilibili
- **密码保护**：白名单操作需要密码验证，防止青少年自行修改
- **实时监控**：自动检测页面新增视频，实时应用过滤规则
- **灵活管理**：支持按平台分组管理，可单独删除或批量清空

## 界面说明

### 视频页
- 显示当前页面可见的所有视频
- 支持缩略图预览
- 可一键将频道添加到白名单
- 合辑/混剪视频单独标记，添加时保留视频URL精确匹配

### 管理页
- 显示当前限制状态（开启/关闭）
- 按平台分组显示已允许频道列表
- 支持删除单个频道或清空指定平台全部频道
- 密码设置/修改功能

## 安装方法

1. 下载本项目代码
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目的 `dist` 目录

## 使用方法

1. 打开 YouTube 或 Bilibili 页面
2. 点击扩展图标，打开弹窗
3. 切换到「视频」标签，点击「重新扫描」
4. 点击视频右侧的「允许此频道」将频道加入白名单
5. 开启限制开关，非白名单视频将被隐藏

## 项目结构

```

├── src/
│   ├── background/          # 后台 Service Worker
│   ├── content/             # 内容脚本（页面注入）
│   │   ├── adapters/        # 平台适配器
│   │   └── observer.ts      # DOM 变化监听
│   ├── popup/               # 弹窗界面
│   ├── shared/              # 共享类型和工具
│   └── styles/              # 通用样式
├── dist/                    # 构建输出目录
├── docs/                    # 设计文档
└── icons/                   # 扩展图标
```

