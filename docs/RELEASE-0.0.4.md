# YouthGuardian v0.0.4 发布说明

## 更新时间
2026-04-10

## 新增功能
- **数据备份与恢复**：在管理页面新增"数据备份"功能，支持导出/导入频道白名单数据为 JSON 文件

## 功能调整
- 移除了无法在开发者模式下稳定工作的云端同步功能（chrome.storage.sync 数据与 extension ID 绑定，删除重装后数据无法恢复）

## 使用说明
- **导出备份**：删除或重装扩展前，请点击"导出备份"保存当前频道数据
- **导入备份**：重装扩展后，点击"导入备份"可恢复之前的频道数据

## 已知限制
- 在 Chrome 扩展管理页面**删除**扩展再**重新加载**时，由于 extension ID 改变，本地存储数据会丢失
- **建议**：如需保留数据，请在删除扩展前先导出备份；或使用"刷新"按钮而非删除重装

## 技术说明
- 数据现在统一存储在 `chrome.storage.local` 中
- 导出格式为标准 JSON，包含 version、exportedAt 和 channels 字段
