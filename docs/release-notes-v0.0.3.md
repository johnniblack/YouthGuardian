## YouthGuardian v0.0.3 发布说明

本次更新主要提升了 YouTube 首页及播放页的过滤稳定性，增强了对动态页面加载的覆盖能力。

### 更新内容
- **优化 YouTube 过滤机制**：
  - 在 YouTube 首页 (`ytd-rich-grid-renderer`) 和播放页 (`ytd-watch-flexy`) 引入了增强型“兜底重试”机制，有效解决页面刷新加载导致的过滤漏网问题。
  - 增强了 DOM 标记校验逻辑，即使在 DOM 节点重用时也能确保过滤状态准确。
- **扩展过滤范围**：
  - 实现了对 YouTube 播放页右侧自动播放列表（即“合辑”播放列表组件 `ytd-playlist-panel-renderer`）的强制隐藏，防止未授权内容自动播放。
- **体验优化**：
  - 优化了代码内部的类型安全与属性处理，提升插件整体运行稳定性。

### 升级建议
1. 建议清理浏览器缓存后重载扩展程序。
2. 如过滤生效后出现短暂延迟（约 1 秒），属于正常兜底重试行为，旨在确保完全拦截未审核内容。

感谢！
