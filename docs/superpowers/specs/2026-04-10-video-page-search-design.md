# 视频页频道搜索功能设计方案 (2026-04-10)

## 1. 任务理解
在 YouthGuardian 插件的 Popup 视频标签页增加一个频道搜索功能。该功能旨在帮助用户在长长的“当前页面可见视频”列表中，通过模糊匹配快速找到并定位特定频道的视频。

## 2. 功能需求
*   **搜索入口**：在“视频”标签页的“当前页面可见视频”标题下方新增搜索框。
*   **交互逻辑**：
    *   **模糊匹配**：输入关键字时，实时从当前已扫描的视频列表中过滤出包含该关键字的频道名称（去重）。
    *   **下拉显示**：弹出一个浮动的下拉列表展示匹配结果。
    *   **高亮选中**：下拉列表展示时，默认选中第一项。支持使用方向键 `↑`/`↓` 切换选中项，`Enter` 键确认。也支持鼠标点击选中。
    *   **定位跳转 (模式 B)**：选中某个频道后，主界面的视频列表自动滚动到该频道的第一个视频位置，并对该视频卡片进行短时间的高亮提醒。
    *   **自动收起**：选中完成后，搜索框内容清空，下拉列表隐藏。

## 3. 技术实现方案

### 3.1 UI 组件
*   **HTML (src/popup/popup.html)**:
    *   在 `#tab-videos` 内新增 `.search-container`，包含 `<input type="text" id="channel-search">` 和一个绝对定位的 `.search-dropdown`。
*   **CSS (src/popup/popup.css)**:
    *   定义 `.search-container` 的样式，确保与现有 UI 风格统一。
    *   定义 `.search-dropdown` 及其子项 `.search-item`、`.search-item.active` 的样式。
    *   定义视频卡片的高亮动画（例如 `.video-item-highlight`）。

### 3.2 逻辑实现 (src/popup/popup.ts)
*   **状态管理**：维护当前匹配的频道列表、当前选中的索引、以及下拉列表的显示状态。
*   **事件监听**：
    *   `input` 事件：触发模糊匹配逻辑，填充下拉列表并显示。
    *   `keydown` 事件：处理 `ArrowUp`、`ArrowDown`、`Enter`、`Escape` 按键。
    *   `blur`/`focus` 处理：点击外部或失去焦点时隐藏下拉列表。
*   **滚动定位**：使用 `Element.scrollIntoView({ behavior: 'smooth', block: 'center' })` 实现平滑滚动跳转。
*   **视觉反馈**：通过 `classList.add` 临时添加高亮类名，并在 1.5s 后通过 `setTimeout` 移除。

## 4. 涉及文件
*   `src/popup/popup.html`
*   `src/popup/popup.css`
*   `src/popup/popup.ts`

## 5. 风险点
*   **DOM 冲突**：搜索框的绝对定位下拉列表可能被父容器的 `overflow: auto` 裁剪，需要处理 z-index 或定位方式。
*   **性能**：如果列表极长，频繁操作 DOM 渲染下拉项可能略有延迟（但在 Popup 场景下通常视频数量有限，风险较低）。
*   **滚动交互**：如果选中的视频正在被过滤（隐藏状态），则需要确保定位逻辑的鲁棒性。

## 6. 验证标准
*   输入不完整关键字能正确列出相关频道。
*   键盘上下键能顺滑切换选中项，背景色有明显变化。
*   回车后，Popup 列表自动滚动到对应视频并闪烁高亮。
*   外观风格与现有插件“暖橙”风格完全一致。
